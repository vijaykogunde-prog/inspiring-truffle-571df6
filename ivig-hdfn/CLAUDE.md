# Project

Question: IVIG in neonatal alloimmune HDFN — evidence synthesis and unit guideline.

# Non-negotiable rules

1. **Citation integrity.** Nothing enters any file unless it was retrieved this session and carries a verified PMID or DOI. If you cannot verify a reference, it goes on `05-references/could-not-verify.md` and is excluded — never included with a hedge. Do not cite from memory, including items in the brief's §10 seed literature.
2. **Numbers as reported.** Effect sizes, CIs, rates, doses, thresholds and denominators are transcribed exactly, never re-derived or rounded. Mark `[abstract only]` where full text was unavailable. If a number is not in the source, the claim carries no number.
3. **Units.** Record bilirubin in the unit reported. Where converting mg/dL ↔ µmol/L for the guideline, show the conversion (1 mg/dL = 17.1 µmol/L) and mark it `[converted]`.
4. **GRADE on every interventional claim.** High / Moderate / Low / Very low, with a one-line reason naming the downgrading domain (risk of bias, inconsistency, indirectness, imprecision, publication bias).
5. **Directness.** Flag whether evidence is from the target population (e.g. term Rh-D disease) or extrapolated (e.g. ABO data applied to Rh, term data applied to preterm, older-era trials without modern intensive phototherapy).
6. **Era effects.** For every trial, record the co-intervention standard (phototherapy intensity, exchange thresholds, prior intrauterine transfusion). The early positive trials and the later null trials differ on these; that difference is likely the central finding, not a footnote.
7. **Nulls get equal billing.** Actively search for null and non-replicating trials and give them the same prominence as positive ones.
8. **Guidance ≠ evidence.** Grey literature (NICE, AAP, NHS England, BSH, SPCs) goes in a separate table and is never counted as peer-reviewed evidence. Record document version and date accessed.
9. **Write to disk incrementally.** Append every search to `01-search-log/searches.md` as it runs. Never hold a phase in context alone.
10. **Absence is a finding.** If a question (e.g. optimal repeat-dose interval, preterm-specific efficacy) has no direct evidence, write "No direct evidence identified" and state what the recommendation rests on instead.

See `RESEARCH-BRIEF.md` for the full brief (research questions, domain structure, search strings, extraction schema, deliverables).
