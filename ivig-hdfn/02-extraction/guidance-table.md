# Guidance and governance documents — grey literature table (Domain F)

Per CLAUDE.md rule 8, this table is grey literature (guidance/commissioning/product-labelling documents) and is **never counted as peer-reviewed evidence**; it is kept separate from the extraction/evidence tables (`extraction.csv`, Domains A–E). Where a document has a genuine companion peer-reviewed publication, that PMID/DOI is given, but the guidance document itself remains grey literature. Rows appended by Domain F (guidance and governance); if a prior domain (E) added rows to this file for SPC/MHRA/SHOT material, they are preserved above/below as originally written.
